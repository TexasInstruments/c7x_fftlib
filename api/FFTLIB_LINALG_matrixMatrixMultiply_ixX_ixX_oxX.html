    FFTLIB_LINALG_matrixMatrixMultiply_ixX_ixX_oxX¶

    group FFTLIB_LINALG_matrixMatrixMultiply_ixX_ixX_oxX

    Kernel for multiplying two matrices.

    • The kernel takes an (m x k) matrix and multiplies it with a (k x n) matrix to produce an (m x n) matrix.

    • C = AB

    FFTLIB_STATUS FFTLIB_LINALG_matrixMatrixMultiply_ixX_ixX_oxX_exec(FFTLIB_kernelHandle handle, const void *src0, const void *src1, void *dst)¶

    This function is the main compute function, and performs matrix-matrix multiplication.

    Remark

    Application is expected to call the checkParams function prior to this function as it avoids check of paramaters for each invocation.

    Assumptions:

    • I/O buffer pointers are assumed to be not aliased.

    Performance Considerations:

    • For best performance, the following parameter settings are recommended:

      • Align all pointers to 8 byte boundaries

      • Set all matrix dimensions to a multiple of

        • 64 for 8-bit data

        • 32 for 16-bit data

        • 16 for 32-bit data
