    FFTLIB_fft1dBatched_i16sc_c16sc_o16sc¶

    group FFTLIB_fft1dBatched_i16sc_c16sc_o16sc

    Kernel for computing batched 16-bit integer FFT.

    • The size of data is required to be a power of 2.

    • The kernel requires application to provide a pre-generated twiddle factors along with the input data.

    Defines¶

    FFTLIB_FFT1DBATCHED_I16SC_C16SC_O16SC_PBLOCK_SIZE¶

    Macro to define the array size for storing SE/SA parameters.
